# rules.md - CDS Portfolio

## ১. কী কী ব্যবহার করতে হবে (What to use)
- **HTML/CSS/JS:** কোনো ভারী ফ্রেমওয়ার্ক (যেমন React বা Vue) ব্যবহার করা যাবে না। শুধুমাত্র কোর টেকনোলজি ব্যবহার করে ওয়েবসাইট বানাতে হবে।
- **Tailwind CSS:** লেআউট এবং ইউটিলিটি ক্লাসের জন্য Tailwind CSS ব্যবহার করা হবে, তবে কাস্টম ডিজাইন এবং থিমের জন্য Vanilla CSS-ও থাকবে।
- **সিমেন্টিক ট্যাগ:** HTML5 এর সঠিক ট্যাগ (`<header>`, `<nav>`, `<section>`, `<footer>`) ব্যবহার করতে হবে।
- **MySQL কানেকশন:** ব্যাকএন্ডের জন্য PHP বা Node.js এর মাধ্যমে MySQL কানেক্ট করতে হবে (পরবর্তীতে নির্ধারিত হবে)।
- **ভাষা:** ওয়েবসাইটটি বাংলা এবং ইংরেজি উভয় ভাষায় সাপোর্ট করতে হবে।

## ২. কী কী এড়িয়ে চলতে হবে (What to avoid)
- **ভারী লাইব্রেরি:** অপ্রয়োজনীয় জাভাস্ক্রিপ্ট লাইব্রেরি ব্যবহার থেকে বিরত থাকতে হবে যাতে সাইট স্লো না হয়।
- **ইনলাইন সিএসএস (Inline CSS):** HTML ফাইলের ভেতরে `style="..."` ব্যবহার করা যাবে না।
- **জটিলতা (Over-engineering):** সহজ এবং ক্লিন কোড লিখতে হবে।
